# Bronze Layer

The Bronze layer is the raw ingestion layer of the Medallion Architecture.
Its purpose is to preserve the original streaming events while storing
them in Delta Lake for reliable, scalable processing.

## Responsibilities

- Read raw Parquet event files generated by the event generator
- Preserve the original event data
- Add ingestion metadata (for example, ingestion timestamp and source file)
- Store data as Delta tables
- Support schema evolution and ACID transactions
- Provide a reliable source for downstream Silver transformations

## Folder Structure

```
bronze/
├── bronze_ingestion.py   # Main ingestion pipeline
├── schema.py             # Spark schema definitions
├── config.py             # Pipeline configuration
└── README.md             # Bronze layer documentation
```

## Design Principles

- No business transformations
- Preserve raw data
- Idempotent pipeline design
- Schema enforcement
- Partitioned Delta tables
- Production-ready project organization
